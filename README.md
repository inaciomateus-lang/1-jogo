Meu Jogo 2D
Sobre o projeto
Jogo 2D desenvolvido com HTML, CSS e JavaScript.
Funcionalidades
- Movimentação do personagem
- Pulo e interação com plataformas
- Sistema de disparos
- Recursos gráficos e de áudio
Controles
- W ou Seta para cima (↑): saltar
- A ou Seta para a esquerda (←): mover para a esquerda
- D ou Seta para a direita (→): mover para a direita
- Z ou Barra de espaço: disparar
Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo index.html no navegador.
Se o jogo precisar de um servidor local para funcionar corretamente, inicie-o antes de abrir o jogo.
